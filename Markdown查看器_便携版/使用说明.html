Markdown 查看器 · 使用手册

一个零依赖、纯本地的轻量 Markdown 阅读器：双击 MdViewer.exe 即用，支持拖拽打开、目录导航、正文搜索、双击就地编辑、深色 / 浅色主题、一键打印 PDF，还能让电脑里的 .md 文件直接显示本图标、双击即用本程序打开。

一、快速开始

  1. 把整个 MdViewer 文件夹（或解压后的便携版）拷贝到任意位置（U 盘、另一台电脑均可）。
  2. 双击 MdViewer.exe —— 会自动在浏览器打开一个本地窗口，无需安装、无需联网。
  3. 把 .md / .markdown 文件拖进窗口，或点右上角「📂 打开 .md」选择文件，即可阅读。

所有解析都在你本机完成，文件不上传任何网络。

二、如何打开文档

方式操作
拖拽把 .md 文件拖到窗口任意位置，松开即打开
按钮点右上角「📂 打开 .md」→ 选择文件
右键 / 双击先运行「安装关联.bat」，之后双击任意 .md 文件即直接用本程序打开
命令行MdViewer.exe 说明.md（可在批处理 / 脚本里调用）

双开：同时打开多个不同的 .md，每个文件是独立的浏览器标签，互不干扰。

空窗口唯一：只双击 MdViewer.exe（不带文件）时，无论双击多少次，都只会聚焦已打开的那个空窗口，不会堆出一堆空标签页。

三、界面说明

  • 左侧目录：打开文档后，自动按标题（H1/H2/H3）生成目录，点击跳转、滚动时高亮当前章节。
  • 右上角搜索：输入关键字，正文实时高亮匹配。
  • ✏️ 编辑：开启编辑模式后，双击正文任意区块（标题、段落、列表、表格、代码块、引用）即可就地修改，保存后直接写回源文件并立即重新渲染——不用再去找 txt 编辑器。
  • 🌗 主题：切换深色 / 浅色；选择会被记住，下次打开沿用。
  • 🖨 打印：一键调起打印（可「另存为 PDF」）。打印效果为干净黑字白底，适合存档。
  • ⏻ 退出：关闭后台服务并退出；所有窗口一起关闭。

底部状态栏的绿灯表示本地服务正常；若服务断开，会弹出「重试连接」提示。

四、就地编辑（改内容不用开别的软件）

  1. 双击正文里的任意一段（如某个标题或某行文字）→ 弹出编辑框，里面是该区块的原始 Markdown 源码。
  2. 直接改文字 → 点「保存并写回文件」（或按 Ctrl+Enter）。
  3. 保存后立即生效：改动写回 .md 源文件（可用任意编辑器验证），页面同时重新渲染，阅读位置保持不变。
  4. 改错了不想保存 → 点「取消」或按 Esc。

说明：

  • 编辑模式默认开启（按钮显示「✏️ 编辑中」）；再点一次按钮可关闭，关闭后双击不会弹编辑框。
  • 编辑以区块为单位（一个标题 / 一段 / 一张表格 / 整个列表），对应源文件里的那几行。
  • 拖进来或临时选择的文件不能写回（内容没有落盘路径），此时编辑按钮不显示；只有双击 .md / 命令行 / 关联打开的真实文件才支持保存写回。
  • 保存时保留文件原有的换行风格（CRLF/LF）与 UTF-8 编码。

五、文件关联（让 .md 显示本图标、双击打开）

  1. 进入便携版根目录，双击 安装关联.bat（无需管理员，仅对当前用户生效）。
  2. 黑窗显示「完成」后，.md 文件即显示本查看器图标，双击即可打开。
  3. 若图标没变：在文件夹窗口按 F5 刷新；或重新运行一次 安装关联.bat。
  4. 想恢复系统默认（用记事本打开）：双击 卸载关联.bat。

提示：文件夹挪到别的电脑后，重新运行一次 安装关联.bat 即可再次关联。

六、常见问题

Q：双击 .md 还是用记事本打开？ A：先运行过「安装关联.bat」了吗？运行后按 F5。若仍不行，检查是否被其它软件抢占（右键 .md → 打开方式 → 选 MdViewer.exe）。

Q：打印出来的 PDF 字体看不清？ A：已优化为白底黑字，正常「打印 / 另存为 PDF」即可；若浏览器勾选了「背景图形」，关掉即可更干净。

Q：换电脑后图标没了？ A：关联是写入注册表的，换电脑需重新运行「安装关联.bat」。程序本身可直接拷贝运行。

Q：后台服务会不会常驻占资源？ A：所有窗口关闭且 30 分钟无活动后，后台服务会自动退出；也可点「⏻ 退出」立即关闭。

Q：支持哪些 Markdown 语法？ A：标题、列表（有序 / 无序 / 嵌套）、引用、代码块、表格、加粗 / 斜体、链接、分割线、删除线、高亮等常用语法。
