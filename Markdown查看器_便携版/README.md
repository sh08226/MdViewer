# Markdown 查看器（轻量 · 本地离线 · 免安装）

一个**双击即用**的 Markdown 阅读工具：把任意 `.md` 文件拖进窗口，或点「打开 .md」，
就能像看网页一样阅读，自带目录、搜索、深色/浅色切换、打印导出 PDF。

## 特点
- **可拷贝、双击即用**：整包压缩发给别人，对方解压双击 `MdViewer.exe` 即可，无需安装 Python、无需联网。
- **本地离线**：所有解析在本机完成，文档不上传任何服务器。
- **纸感界面**：暖白底、墨色字、低饱和靛蓝点缀，安静不喧宾夺主。
- **好读**：默认纸感浅色（暖白底 + 墨色字 + 低饱和靛蓝点缀，界面退后、内容向前），可一键切换深色并记忆选择；自动生成右侧目录、正文搜索高亮；打印/导出 PDF 时自动转为黑字白底，清晰可读。
- **够用**：支持标题、列表（含嵌套）、引用、代码块、表格、粗体/斜体/删除线、链接、图片等常用语法。

## 用法
1. 直接双击 `MdViewer.exe`（或桌面快捷方式）。
2. 把 `.md` 文件拖到窗口，或点右上角「📂 打开 .md」。
3. 想直接打开某个文件，也可在命令行运行：`MdViewer.exe 说明.md`。

## 让 .md 文件“认得”这个查看器（双击即用 + 专属图标）
不想每次都先开程序再拖文件？运行一次下面的批处理，就能让电脑里所有 `.md` /
`.markdown` 文件显示本查看器的图标，并且**双击直接用本查看器打开**：

- **`安装关联.bat`** — 双击运行（无需管理员）。它会把 `.md` 关联到本查看器，
  并把文件图标设成本查看器的图标。拷贝到别的电脑后，重新运行一次即可重新关联。
- **`卸载关联.bat`** — 想恢复系统默认程序（或弹出选择框）时运行它，一键取消关联。

> 说明：关联只写「当前用户」的注册表，不影响其它账户，也不需要管理员权限。
> 若双击后图标没立刻变化，在文件夹里按 `F5` 刷新即可。
> 注意：关联记录里写的是**当前 exe 所在的绝对路径**——以后如果把整个文件夹
> 挪到别的位置，记得再跑一次「安装关联.bat」刷新路径。

## 常见问题
- **提示「本地服务未连接」／打开文件报 Failed to fetch**：
  说明这个网页背后的查看器程序已经退出了（常见于：浏览器里留着旧标签页，而程序早已关闭）。
  **重新双击 `MdViewer.exe`**，用新弹出的窗口即可；旧标签页可以直接关掉。
  界面左下角的状态灯会实时显示：绿灯＝服务正常，红灯＝服务未连接（此时会弹出带「重试」按钮的提示）。

## 给开发者：自己打包
```bat
prepare_buildenv.bat   :: 仅首次：创建构建环境（装 pyinstaller + pillow）
build.bat              :: 打包成 dist\MdViewer\（单文件夹，含 exe）
run.bat                :: 直接运行打包后的 exe
```
打包用 PyInstaller onedir；本工具只读取文件、不写系统目录，故不带管理员清单，双击不弹 UAC。

## 源码结构
- `mdviewer.py` — 本地 HTTP 服务入口（纯标准库）。
- `mdrender.py` — 手写 Markdown→HTML 渲染器（纯标准库，零依赖）。
- `frontend.py` — 科技蓝前端界面（内联 HTML/CSS/JS）。
- `assets/icon.ico` — 查看器图标（同时作为 `.md` 文件关联图标）。
- `安装关联.bat` / `卸载关联.bat` — 一键设置 / 取消 `.md` 文件关联与图标。
